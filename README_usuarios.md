# 🎓 CREDENCIALES Y CUENTAS OFICIALES — SISTEMA TUTORMATCH EMI

Este documento contiene la lista completa de credenciales oficiales precargadas en la Base de Datos (`PostgreSQL` / `store.js`) para ingresar a la plataforma **TutorMatch - EMI Cochabamba**.

---

## 🔐 Instrucciones de Ingreso al Sistema

1. **URL de Acceso:** [http://localhost:5173/html/index.html](http://localhost:5173/html/index.html) -> Clic en **"Ingresar"** (o directamente en la pantalla de Login).
2. **Sin selector de rol:** El sistema detecta automáticamente si la cuenta es de **Estudiante** o de **Docente Tutor** y te redirige a su panel correspondiente.
3. **Credenciales:**
   - **Correo Institucional:** `@est.emi.edu.bo` (estudiantes) o `@adm.emi.edu.bo` (docentes).
   - **Contraseña / Código SAGA:** Tu código SAGA oficial (respetando mayúsculas y guiones, ej. `C11550-9` o `DOC-1001`).
