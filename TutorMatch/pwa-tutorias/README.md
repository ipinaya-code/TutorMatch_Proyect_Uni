# TutorMatch — PWA de Tutorías Universitarias

React + Vite + Tailwind. Carpetas: html/ css/ js/ (components, pages, data, utils) public/

## Ejecutar

1- entrar a la carpeta de TutorMatch donde es q esta el programa completo
2- entrar a pwa-tutorias
ahi hacer correr estos comandos:

npm install
npm run dev

## cmd ejecutar

1- cd .\TutorMatch\
2- ls
3- cd .\pwa-tutorias\
ejecutar:
npm run dev
